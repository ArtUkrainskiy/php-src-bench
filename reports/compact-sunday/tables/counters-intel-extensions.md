# Native counter tables: intel-extensions

[Interpretation](../README.md). Generated by bench table from the native bench compare files. CPU cycles and retired instructions are measured separately from the elapsed-time cohort. Negative means fewer cycles/instructions. Original A/A controls are retained. The instructions column aggregates compiler deltas as defined by bench table; per-compiler exact counts are in the linked JSON rows.

**One mbstring A/A pair was disturbed.** See [the exact pair and fresh validation](aa.md#disturbed-native-control); do not treat that original pair as a quiet control.
